# SF_FluffyMachines v26.2.19 — Release candidate

This document describes the **proposed new immutable release**. It is not proof that the version has been published. The only committed production change since v26.2.18 is the Quick Withdraw correction merged from [#42](https://github.com/wickidcow/SF_FluffyMachines/pull/42).

## Fixes

- **Fluffy Barrel Quick Withdraw:** when Cargo has emptied the first physical output buffer (slot 24) while the second (slot 25) still contains matching items, Quick Withdraw now skips empty barrel output slots and transfers remaining stock correctly. Previously it could repeatedly check slot 24 and strand slot 25.
- Keep the existing exact Slimefun identity/metadata checks, saved reserve and Cargo transfer behavior unchanged; the patch does not rewrite historical items or storage.
- CI's Apache Maven 3.10.0 setup now falls back to the official Apache archive when the live mirror returns 404. The original pinned SHA-512 verification is retained.

## Acceptance evidence required

- Java 21 canonical raw JAR `SF_FluffyMachines26.2.19.jar`, verified plugin.yml/manifest and same-run SHA-256 artifact roundtrip.
- Maven Paper 1.21.11 / 26.2 / 26.3 compilation.
- Native Paper 1.21.11 / 26.2 / 26.3 **two-boot** real Cargo source→barrel quantity conservation, quick withdraw with two outputs and second-only output, backpack transfer/restart, typed PDC/Slimefun identity parity.
- Additional checksum-pinned **published Slimefun Legacy 4.1.80** native Cargo/restart smoke on Paper 26.3.
- Exact-head candidate green, merged master checks, and guarded workflow_dispatch publication on master with `publish_release=true`, `release_version=26.2.19`. Existing tag v26.2.18 and all assets remain untouched.

## Not included

- Watering Can PR #41 (still draft, separate player-protection and ExoticGarden acceptance).
- Historical AlbionMC singularity/old-item migration or true owner-world storage count repair. The native disposable registered-item cases do not prove historical live item compatibility.
- Any Slimefun Legacy core or Unified modification.

Do not claim this release fixes all historical Fluffy Barrel counts. Back up existing world and plugin data before installing on AlbionMC.
