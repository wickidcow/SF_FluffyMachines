# FluffyMachines 26.2.18 — Identity-safe barrel item presentation

This release preserves historical Slimefun item identity and barrel counts while narrowing the cosmetic Adventure name/lore compatibility introduced in 26.2.17. The canonical raw Java 21 plugin JAR is `SF_FluffyMachines26.2.18.jar`.

## Fixes

- Barrels no longer treat two registered Slimefun items as interchangeable merely because their Adventure display name or lore has identical flattened text. Meaningful colors, italic styling, decorations, hover/click events, insertion metadata, translation keys and lore line order/count remain protected.
- Historical, unstyled, empty one-child component wrappers are still compatible with the current item presentation. Redundant explicitly-false bold, underline, strikethrough and obfuscation at the root may be ignored where Minecraft already defaults them off. Explicit *italic=false* is **never** ignored; it is significant in Minecraft item names and lore.
- This compatibility path retains the existing same-nonnull-Slimefun-ID requirement and strict matching of nonpresentation ItemStack metadata, including PDC identity, owner/model/enchantments. Unregistered or vanilla items remain strict.
- Barrel physical output stacks, stored counts, Cargo mechanics, recipes, capacities and saved-world data formats are unchanged by this patch. No automated player inventory rewrite or broad item normalization is performed.

## Validation

The exact fix-head workflow checks Maven/JUnit against native Paper 1.21.11, 26.2 and stable 26.3. It includes new regression cases for real text formatting differences, hover/click/insertion events, translations and changed lore structure, while retaining historical wrapper-positive cases. The native restart tests exercise backpack transfers across all three supported Paper versions and barrel/Cargo transfers with the published Slimefun Legacy 4.1.79 core on Paper 26.3.

The distinct release candidate must separately pass exact-version CI, same-run raw JAR integrity and native checks. Passing these tests is not certification for every historical server, custom addon stack, Purpur/Leaf or Folia environment.

## Installation and rollback

Stop the server; back up the world, Slimefun storage, FluffyMachines data/config and plugin JARs. Replace the previous FluffyMachines JAR with only `SF_FluffyMachines26.2.18.jar` and perform a full restart, **not** `/reload`. Do not delete saved barrels or manually reset quantities. For rollback, restore the corresponding server data backup and previous addon JAR together. Nothing is automatically deployed to AlbionMC.
